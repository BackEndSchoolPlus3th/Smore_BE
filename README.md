# MeotsaMose - 멋쟁이 사자처럼 백엔드 부트캠프 플러스 (3rd)
<br><br>

## 프로젝트 개요
**취준생 스터디 통합 플랫폼 Smore**
<br><br>
취준생입장에서 불편함을 줄이기 위한 서비스를 만들고 싶었습니다.<br>
취준생으로 가장 부담이 되는 것을 꼽자면<br>
금전적인 부담과 거주지역 주변에 스터디가 없어 가입이 어려웠던 점입니다.<br><br>
그래서 저희는 스터디를 모집하고 활동하고 자료 정리까지 한 플랫폼을 기획하였습니다.<br>
Smore를 통해 스터디 공간대여에 필요한 비용을 절약할 수 있고, 거주 지역에 상관없이 스터디에 참여할 수 있습니다.<br>

## 주요 기능
:one: 해시태그 기반 스터디 추천 및 검색<br>
:small_blue_diamond: 엘라스틱 서치를 활용한 유사도 기반 스터디 추천<br>
:small_blue_diamond: 엘라스틱 서치를 활용하여 쿼리 검색보다 2배 검색 성능 향상<br><br>

:two: 채팅 & 화상채팅<br>
:small_blue_diamond: WebSocket을 활용한 실시간 채팅 구현<br>
:small_blue_diamond: WebRTC를 활용한 화상 채팅 구현<br><br>

:three: 스터디 자료 관리<br>
:small_blue_diamond: S3 서버를 활용한 파일 관리 구현<br>
