# Smore Project
**온라인 스터디 검색 및 운영 통합 플랫폼**

취준생 입장에서 취준생들의 어려움을 줄여줄 수 있는 서비스를 개발하고 싶었습니다.<br>
취준생에게 가장 부담이 되는 것은 금전적인 부담과<br>
거주 지역 주변에 스터디가 많지 않아 가입이 어렵다는 점입니다.<br>

스모어는 온라인에서 스터디 모집, 운영, 관리, 자료 정리 등 스터디 관련 활동들을 모두 할 수 있습니다.<br>
스터디 공간대여를 위한 비용을 절약할 수 있고, 공간의 제약없이 원하는 스터디에 참여할 수 있습니다.<br>

## 주요 기능 소개
:one: 스터디 추천 및 검색<br>
:small_blue_diamond: 유사도 기반 스터디 추천 서비스<br>
:small_blue_diamond: 엘라스틱 서치를 활용한 해시태그 검색<br><br>
:two: 실시간 채팅 및 화상채팅<br>
:small_blue_diamond: webSocket 활용 실시간 채팅<br>
:small_blue_diamond: webRTC 활용 화상채팅<br><br>
:three: S3 서버를 활용한 자료관리<br>
:small_blue_diamond: S3 업로드를 통한 스터디 자료 통합관리<br>
